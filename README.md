# Spotlight Jungle

Игровой браузерный тренажёр для повторения английского языка за 2 класс по учебнику Spotlight 2.

## Открыть проект

- [Игра-тренажёр](https://podsoblyaeva-sv.github.io/spotlight-jungle-2-class/)
- [Презентационный фильм](https://podsoblyaeva-sv.github.io/spotlight-jungle-2-class/film/)

- 15 дней повторения;
- 62 задания;
- алфавит A–Z и Module 1–5;
- сборка роботов и мультфильмы;
- локальное сохранение прогресса;
- адаптивная тренировка ошибок;
- работа на телефоне и компьютере.

В репозитории находится готовая статическая сборка для GitHub Pages. Игра размещена в корне сайта, а окончательный фильм v14 — в папке `film/`.
