# Spotlight Jungle

Игровой браузерный тренажёр для повторения английского языка за 2 класс по учебнику Spotlight 2.

- 15 дней повторения;
- 62 задания;
- алфавит A–Z и Module 1–5;
- сборка роботов и мультфильмы;
- локальное сохранение прогресса;
- адаптивная тренировка ошибок;
- работа на телефоне и компьютере.

В репозитории находится готовая статическая сборка для GitHub Pages.
